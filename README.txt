MOSSBOUND - COMPLETE GAME

HOW TO PLAY
1. Extract this ZIP into a folder.
2. Double-click index.html to open it in a modern browser.
3. Click the start button in the game.

No installation or build step is required. Chrome, Edge, or Firefox is recommended.
The game runs locally. Optional Google Fonts need an internet connection; the
game remains playable using fallback fonts when offline.

If your browser restricts local files, open a terminal in this folder and run:
  python -m http.server 8000
Then open http://localhost:8000 in your browser.

FILES
index.html - Complete game interface
game.js - All game source code, world generation, combat, sprites and animation
style.css - Interface styles
START-GAME.bat - Opens the game on Windows

CONTROLS
Use the in-game Controls button for the full control list.
A / D or arrow keys: move
Space: jump / ascend while flying
Shift: sprint
Q: dash
F: attack
C: style ability; with Line of Code, tap Destroy or hold for the biome hand
R: mount / special ability, depending on equipped weapon
X: Line of Code Overrun
E: crafting
G: inventory / gear
B: world and mounts
L: fighting styles
I: interact with the sky Admin / sky lift
Escape: pause / close menus

ADMIN
Open Codes and enter ADMIN33 to unlock the Admin panel.
